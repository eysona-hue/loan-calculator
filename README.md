# LoanFlow Calculator

Modern bilingual home and car loan calculator built with React, Vite, Tailwind CSS, Recharts, jsPDF, and jsPDF AutoTable.

## Features

1. English and Spanish language selector
2. Home loan calculator
3. Car loan calculator
4. Fixed rate amortization formula
5. Monthly amortization schedule
6. Extra monthly payment impact
7. PMI estimate for mortgages below 20 percent down
8. Affordability ratios
9. Scenario comparison
10. Improved visual charts
11. CSV export with Excel friendly UTF 8 encoding
12. Professional PDF report export
13. Google AdSense ready placeholder areas
14. Privacy, Terms, About, and Contact pages

## Deployment

This project is ready for Vercel.

Build command:

npm run build

Output directory:

dist

Install command:

npm ci --no-audit --no-fund

## Important disclaimer

This calculator provides estimates only. Actual loan quotes can vary based on lender rules, APR, credit score, payment timing, closing costs, taxes, insurance, dealer fees, escrow, and local regulations.
